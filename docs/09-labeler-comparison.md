# Comparing relevance labelers

Label quality and search quality are different measurements. A higher-reasoning
model is another labeler, not ground truth. Human grades remain authoritative
under the existing override policy.

## Recorded evidence and open work

The [README](../README.md) records GPT-5.4 mini's calibration against 100
human-labeled pairs: 77% exact agreement and 0.802 quadratic-weighted kappa.
See the [calibration report](../data/eval/judge_pilot/report.md),
[decisions](02-decisions.md) and [results](05-results.md) for scope and other
tested models. This is pilot calibration, not independent held-out validation.

Higher-reasoning GPT-6 ASTRA labels were described in the maintenance request.
The development handoff on 2026-11-03 confirmed that no such label set is currently
recorded in this repository. The comparison is planned, awaiting the label
artifact and provenance from the project owner. References to ASTRA in paper
text are not labeler metadata. Do not publish a comparison score, sample count or
claim of completed validation until the underlying records are supplied.
No labels are generated by this document.

## Matched-pair comparison method

1. Locate each label set and verify model identity, collection date, prompt/rubric,
   evidence shown, grade scale and query-paper keys. Distinguish model-generated
   labels from human labels even if someone manually copied the model response.
2. Compare the intersection of identical query-paper pairs with identical source
   text and compatible rubrics. Report each set's size, intersection size,
   exclusions and missing/invalid responses; do not imply equal coverage.
3. Freeze the comparison set before further rubric tuning. Separate calibration
   pairs from fresh validation pairs. Disagreement-selected samples cannot
   establish population-wide agreement without a sampling caveat.
4. Report exact agreement, quadratic-weighted kappa, relevant/not agreement,
   severe 0-versus-2 disagreements and a confusion matrix. Include query-type
   counts and uncertainty, not just the aggregate.
5. Explain representative disagreements using the query and available evidence.
   Record adjudication separately; never overwrite original model responses.
6. Report actual costs, tokens, failures, retries and latency with cache scope.
   If models differ in reasoning settings or evidence access, disclose it.

The reranker's 0-4 scores are not the judge's 0/1/2 labels. Do not silently convert
one into the other or treat reranker explanations as independent judgments.
Model consensus is not correctness, and a judge from the same model family as
the reranker may favor its outputs.

## Presentation

Use a compact table with model/snapshot, rubric, matched-pair count, human-reference
count, agreement metrics, severe errors, cost and validation status. Link the
immutable artifacts and a machine-readable comparison report. Keep search
leaderboard changes separate from labeler agreement results; replacing a label
layer changes the benchmark and requires explicit provenance.
